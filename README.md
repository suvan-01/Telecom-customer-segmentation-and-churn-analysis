# Telecom Customer Segmentation & Churn Dashboard

Run locally:
    pip install -r requirements.txt
    streamlit run app.py

Deploy (Streamlit Community Cloud):
1. Push app.py, requirements.txt and IndiaTelecomData.csv to a GitHub repo (same folder).
2. Go to share.streamlit.io -> New app -> pick the repo, branch, main file = app.py -> Deploy.
